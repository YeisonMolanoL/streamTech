🔧 ARQUITECTURA TÉCNICA
────────────────────────────────────────────────────────────────────────────────

LAYERS:
  Controller → Service → Repository → Entity → Database
  
  CodeReceptionController
       ↓
  LongPollingService
       ├─ CodeAssignmentService (FIFO)
       ├─ ImapManagerService (Background)
       └─ EncryptionService
       
  Repositories (JPA)
       ↓
  MySQL (InnoDB, UTF-8)


FLOWS:

Client Request:
  POST /get-code
    ↓
  Backend:
    1. Create CodeRequest
    2. Start CompletableFuture
    3. Start IMAP listener (background)
    4. Wait future.get(30s)
    
  IMAP Background:
    1. Email arrives
    2. Extract code (regex)
    3. Save to DB
    4. Assign with FIFO (pessimistic lock)
    5. Complete future
    
  Response:
    {success: true, code: "123456"}
    ↓
  Frontend:
    Show code to user


DATABASES:

email_accounts [PK: id]
├─ email (encrypted password)
├─ host, port, secure
└─ is_active

code_requests [PK: id]
├─ email, status (PENDING/ASSIGNED/EXPIRED)
├─ created_at, assigned_code_id
└─ FK: assigned_code_id → codes.id

codes [PK: id]
├─ email, code
├─ is_assigned, created_at
└─ assigned_to_request_id

parsing_rules [PK: id]
├─ service (Google, Microsoft, etc)
├─ regex_pattern
└─ is_active

🎓 CÓMO FUNCIONA (30 segundos)
────────────────────────────────────────────────────────────────────────────────

t=0s:    Usuario ingresa email en Angular
t=0.1s:  Click "Obtener Código" → POST /get-code

BACKEND:
t=0.2s:  Crear CodeRequest(status=PENDING)
t=0.3s:  Crear CompletableFuture
t=0.4s:  Iniciar ImapManager (background @Async)
t=0.5s:  Esperar future.get(timeout=30s) ← NO BLOQUEA

EMAIL ESPERANDO:
t=5s-20s: En espera... background IMAP escucha

EMAIL LLEGA:
t=15s:   Correo entra a INBOX
t=15.1s: IMAP detecta (listener)
t=15.2s: Procesar mensaje
t=15.3s: Extraer código régex: "123456"
t=15.4s: INSERT codes (is_assigned=false)
t=15.5s: CodeAssignmentService:
         SELECT CodeRequest (FOR UPDATE)
         SELECT Code (FOR UPDATE)
         UPDATE ambas tablas
         COMMIT
t=15.6s: future.complete(response)
t=15.7s: Response HTTP 200 OK

FRONTEND:
t=15.8s: Angular recibe {success: true, code: "123456"}
t=16s:   UI muestra código
         Usuario ve: "123456" con botón [Copiar]
